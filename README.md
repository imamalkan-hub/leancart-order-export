Exports orders with their line items to CSV in one click.

**Example site:** https://gumgraftcostguide.com
**Category:** Orders · **License price:** $24 (Business Bundle: $149)

## Features
* Date and status filter
* CSV including line items
* Excel formula injection protection
* HPOS compatible (wc_get_orders)

## Installation
1. Download the ZIP from `build/zips/` or download this repository as a ZIP.
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin.
3. Activate the plugin and configure it at **Settings → LeanCart Order Export**.

## Requirements
- WordPress 6.2+, PHP 8.0+
- WooCommerce 8+ (HPOS compatible)
